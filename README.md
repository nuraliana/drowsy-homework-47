One line, in the dog's own voice: the dog's excuse for eating the homework.

Run it with:

```sh
python3 main.py
```

It writes the entry to `entry.txt` inside the directory given by
`MAKEFUN_OUTPUT_DIR` (default `/output`).

The joke lands because the dog obeys the scolding literally, trading the couch for the homework as its new lesson.
main.py prints that single excuse to entry.txt so the submission stays one clean line.
